Exact source access
-------------------
The accompanying source/ffmpeg directory contains the exact FFmpeg source, the
original and modified build scripts, the dependency sources linked into these
executables, and original Rust crate sources recovered from the actual build
cache. File hashes and release paths are recorded in ffmpeg/manifest.json.
Instructions, source selection and provenance are in ffmpeg/SOURCE-README.txt,
source-inventory.json, rav1e-cargo-inventory.json and build-provenance.json.

Keep the complete source sidecar available with the executable download and
retain this notice and the component notices in the application. The source
archives are intentionally excluded from the lightweight Git repository;
their absence from Git does not remove the distribution requirement.
